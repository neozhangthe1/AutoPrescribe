INTRODUCTION                                    *kimi*

A Vim plugin that integrates Kimi AI (by Moonshot) into your workflow for
AI-powered chat and code completion assistance.

COMMANDS                                        *kimi-commands*

:KimiChat                                      *:KimiChat*
        Opens the Kimi chat interface in a new window.

:[range]KimiComplete [instruction]             *:KimiComplete*
        Sends the selected code to Kimi for completion or modification based on
        the given instruction.

CONFIGURATION                                  *kimi-configuration*

g:kimi_api_key                                 *g:kimi_api_key*
        Your Kimi API key from Moonshot Platform.
        Default: ''

g:kimi_map_chat                                *g:kimi_map_chat*
        Mapping to open the chat interface.
        Default: '<Leader>kc'

g:kimi_map_complete                            *g:kimi_map_complete*
        Mapping to trigger code completion.
        Default: '<Leader>ki'

g:kimi_model                                   *g:kimi_model*
        The Kimi model to use.
        Default: 'moonshot-v1-8k'
        Options: 'moonshot-v1-8k', 'moonshot-v1-32k', 'moonshot-v1-128k'
